Privacy notice

Effective 31 October 2026

YouTube Channel Analytics is a personal desktop tool operated by the owner of Small Tales, Big History to analyse their own channel. This notice describes the current local collector.

Data accessed

With the owner's Google consent, the tool accesses the channel identifier and profile, upload metadata, public video statistics, thumbnails, and authorised channel and video performance reports. Reports may include views, watch time, average viewing duration, retention, traffic sources, subscriber changes and thumbnail impressions and click-through rates where available. These are aggregate reports, not a list of individual viewers.

Purpose and permissions

Data is used to create local performance reports and support the owner's content-improvement decisions. The tool requests only youtube.readonly and yt-analytics.readonly. It may create or reuse a YouTube Reporting API job so that Google generates daily analytics reports. It does not modify or publish channel content.

Storage and protection

Collected reports, downloaded public thumbnails and configuration files are stored on the owner's computer. OAuth tokens are protected using Windows Data Protection API encryption tied to the Windows user. Local credential and analytics folders are excluded from the project's Git tracking. The local OAuth client configuration is not published on this website.

Sharing and AI assistance

The collector communicates with Google's APIs and does not automatically send analytics to a separate AI API. At the owner's direction, selected report data may be shared with an AI assistant, including ChatGPT or Codex, for interpretation. That service then processes the supplied data under its applicable account terms and privacy settings. The public website contains no private analytics or credentials. The tool does not sell Google user data or use it for advertising.

YouTube Channel Analytics' use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and deletion

Reports and credentials remain on the owner's computer until removed by the owner, subject to applicable Google and YouTube API data-refresh and deletion requirements. The owner controls local backups and shared copies. To remove local data, the owner can delete the collector's credential, data and report folders, including backups they created.

Revoke access

The owner can revoke the app's Google access through Google Account connections. Revoking access prevents future authorised API collection but does not automatically delete previously saved local reports or copies already shared with another service.

This informational website

The site's pages contain no custom analytics, advertising scripts, tracking pixels or sign-in forms. If hosted on GitHub Pages, GitHub processes visitor information, including IP addresses for security, under the GitHub Privacy Statement. External links are subject to their respective services' policies.

Questions and changes

This tool is used only by its channel owner. Questions about the tool can be directed to the owner through the contact options, where available, on the linked channel. This notice will be updated if the tool's data practices change.
